# wiretrip

suspicious automation detection for discord.

wiretrip watches for behavior that looks difficult to do by hand: fast cross-channel activity, unusual timing, ghost typing, burst patterns, suspicious webhook activity, and other signals that can point to selfbot-style automation or compromised accounts.

it is built to help moderators review what happened before taking action.

## what it is

- a discord security bot
- focused on behavior signals, not message-content scanning
- designed for review-first moderation
- useful as an extra layer next to discord automod

## what it is not

- not a general-purpose moderation suite
- not an xp, music, reaction-role, or utility bot
- not a promise of zero false positives
- not a replacement for human moderation
